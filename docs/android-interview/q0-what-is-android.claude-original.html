Q0. 안드로이드란 무엇인가요?

확인 질문에 직접 답하기

빈칸 열기 → 카드 뒤집기 → 탑 탐험 → 요청 여행 → 퀴즈. 행동할 때마다 XP가 쌓임.

Step 1 · 30초 답변

면접에서 첫 문장으로 말할 정의

밑줄을 눌러 빈칸을 채워 볼 것. 먼저 머릿속으로 떠올린 뒤 열기.

안드로이드는 스마트폰·태블릿 같은 모바일 기기를 위해 설계된 오픈소스 운영체제. 구글이 개발·유지 관리하며 리눅스 커널에 기반함. 광범위한 하드웨어 구성과 기기를 지원하는 유연한 플랫폼을 제공함.

학습 팁: 정의를 설명한 뒤 주요 특징과 계층 구조를 연결해 보세요.
Step 2 · 5대 특징

안드로이드 OS의 주요 특징

카드를 눌러 뒤집기. 앞면만 보고 설명을 먼저 말해 보면 기억에 더 오래 남음.

Step 4 · 각주 속 보물

ART의 AOT와 JIT, 언제 기계어가 되나

책 각주에 숨어 있는 개념. 면접에서 ART를 말하면 꼬리 질문으로 자주 이어짐.

AOT (Ahead-of-Time)
미리 컴파일바로 실행
런타임 전에 기계어로 변환. 실행 중 JIT가 필요 없어 런타임 오버헤드가 줄어듦.
JIT (Just-in-Time)
실행변환실행변환
실행 직전에 동적으로 변환. 실제 실행 패턴을 보고 자주 쓰는 코드 경로를 최적화함.
